Транзистор гэж юу вэ?

Транзистор нь гурван хөлтэй хагас дамжуулагч элемент бөгөөд нэг хөлийн жижиг дохиогоор нөгөө хоёрын хоорондох гүйдлийг удирддаг. Үндсэн хэрэглээ: өсгөх (analog) ба түлхүүр (switch, digital).

Ангилал

  1. Биполяр (BJT): хоёр p–n шилжилттэй, гүйдлээр удирдагдана. Төрөл: n-p-n, p-n-p. Хөл: Эмиттер (Э), Бааз (Б), Коллектор (К)
  2. Талбайн (FET): хүчдэлээр удирдагдана, нэг төрлийн зөөгч (унипoляр). Хөл: Source (S), Gate (G), Drain (D)
    • JFET — p–n шилжилттэй Gate
    • MOSFET — тусгаарлагдсан (оксид) Gate; индуцирсэн / суулгасан сувагтай
  3. Бусад: IGBT (BJT+MOSFET хосолсон, чадлын), фототранзистор, Дарлингтон хос
  4. Чадлаар: бага (< 0.3 Вт), дунд, их чадлын (радиатортай); Давтамжаар: нам, өндөр, СВЧ

Биполяр транзисторын бүтэц (n-p-n)

Биполяр n-p-n

Гүйдлээр удирдагдана: IК = β·IБ. Хамгийн түгээмэл. Ж: BC547, 2N2222, КТ315.

Биполяр p-n-p

n-p-n-ийн туйл эсрэг. Эмиттер гүйдэл дотогш. Ж: BC557, 2N2907, КТ361.

JFET (n-суваг)

Хүчдэлээр удирдагдана; UGS < 0 сувгийг нарийсгана. Өндөр оролтын эсэргүүцэл. Ж: 2N5457, BF245.

JFET (p-суваг)

n-сувгийн эсрэг туйлт. Ж: 2N5460, J176.

MOSFET (n-суваг, индуцирсэн)

Тусгаарлагдсан Gate; UGS > Uth үед нээгдэнэ. Чадлын электроник, тоон хэлхээ. Ж: IRF540, 2N7000.

MOSFET (p-суваг)

n-сувгийн эсрэг туйлт; CMOS-ийн хос элемент. Ж: IRF9540, BS250.

Ажиллах зарчим (n-p-n, идэвхтэй горим)

ЭБ шилжилтийг шууд, БК шилжилтийг урвуу хүчдэлээр холбоно. Эмиттерээс баазад цацагдсан электронуудын ихэнх (α ≈ 0.98–0.998) нь нимгэн баазыг давж коллекторын урвуу орон руу татагдана. Зөвхөн бага хэсэг нь баазын нүхтэй рекомбинацлаж бааз гүйдэл үүсгэнэ.

IЭ = IК + IБ,   IК = β·IБ,   β = h21э = α/(1−α) ≈ 50…500

Бааз гүйдлийг өөрчилж коллектор гүйдлийн хариу үйлдлийг ажигла:

IБ = 40 мкАβ = 100IК = 4.0 мА

Ажлын горимууд

Таслалт (cutoff)

ЭБ ба БК хоёулаа урвуу. IБ ≈ 0, IК ≈ 0. Түлхүүр нээлттэй (OFF).

Идэвхтэй (active)

ЭБ шууд, БК урвуу. IК = β·IБ. Өсгөгч горим — шугаман.

Ханалт (saturation)

ЭБ ба БК хоёулаа шууд. UКЭ ≈ 0.1–0.3 В, IК хэлхээгээр хязгаарлагдана. Түлхүүр хаалттай (ON).

Урвуу идэвхтэй

ЭБ урвуу, БК шууд. Э ба К байрлаж солигдсон мэт; β маш бага. Ховор хэрэглэнэ.

MOSFET-ийн ажиллах зарчим (n-суваг, индуцирсэн)

Gate-д эерэг хүчдэл өгөхөд p-субстратын гадаргууд электронууд татагдаж n-суваг индуцирлэгдэнэ (UGS > Uth). Сувгийн эсэргүүцэл Gate-ийн хүчдэлээс хамаарна; Gate-ээр гүйдэл урсахгүй (оролтын эсэргүүцэл ~10¹²–10¹⁴ Ом).

UGS = 1.0 ВUth = 2 В

Статик характеристикууд (ерөнхий эмиттерийн схем)

Оролтын: IБ(UБЭ) — диодын шууд салбартай төстэй (UБЭ ≈ 0.7 В). Гаралтын: IК(UКЭ) — IБ = const бүрт нэг муруй. Ачааллын шугам ба ажлын цэг (Q) огтлолцол дээр байна.

Үндсэн параметрүүд

  1. β (h21э) — гүйдлийн өсгөлтийн коэффициент; α = IК/IЭ ≈ 0.99
  2. UКЭ max, IК max, PК max — хязгаарын утгууд (ж: BC547: 45 В, 100 мА, 0.5 Вт)
  3. fT — өсгөлт 1 болох давтамж; UКЭ нас — ханалтын хүчдэл (0.1–0.3 В)
  4. IКБО — коллекторын урвуу гүйдэл (температураас хүчтэй хамаарна)
  5. FET: S = ΔID/ΔUGS — налалт (transconductance), Uth — босго хүчдэл, RDS(on) — нээлттэй сувгийн эсэргүүцэл

Схемийн тэмдэглэгээ

BJT: сумтай хөл — эмиттер; сум гадагш = n-p-n, дотогш = p-n-p ("Not Pointing iN"). FET: сум субстрат/Gate дээр; n-суваг — сум дотогш (сувгийн зүг), p-суваг — гадагш. MOSFET-ийн тасархай шугам = индуцирсэн суваг.

Үсэг-тоон тэмдэглэгээ

  1. JEDEC: 2N#### — "2" = хоёр шилжилт (транзистор). 2N2222 (npn), 2N3055 (чадлын npn), 2N7000 (MOSFET)
  2. Pro Electron: 1-р үсэг материал (A=Ge, B=Si), 2-р үсэг: C=НД бага чадлын, D=НД чадлын, F=ӨД, S=түлхүүр. BC547, BD139, BF199, BS170
  3. JIS (Япон): 2SA (pnp ӨД), 2SB (pnp НД), 2SC (npn ӨД), 2SD (npn НД), 2SK (n-FET), 2SJ (p-FET). 2SC1815
  4. ГОСТ: КТ (кремний транзистор), ГТ (германий), КП (талбайн). КТ315, КТ361, КТ818, КП303
  5. Үйлдвэрийн: IRF### (International Rectifier MOSFET), TIP### (Texas чадлын), MJE###
